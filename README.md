# SyntaxWear - Tênis e Sneakers Online 👟

Bem-vindo ao repositório da **SyntaxWear**, uma loja virtual moderna e elegante especializada em calçados que unem estilo, conforto e atitude. Este projeto foi desenvolvido para oferecer uma experiência de compra intuitiva e visualmente atraente para entusiastas de sneakers.

---

## 🚀 Sobre o Projeto

A SyntaxWear é um e-commerce focado no mercado de calçados urbanos e esportivos. O site foi construído com foco em design responsivo e componentes reutilizáveis, garantindo que o usuário tenha uma ótima experiência tanto no computador quanto no celular.

O nome **SyntaxWear** reflete a fusão entre o mundo da tecnologia (Syntax) e a moda urbana (Wear), trazendo um conceito futurista e moderno para a marca.

---

## ✨ Funcionalidades

- **Design Responsivo:** O site se adapta perfeitamente a diferentes tamanhos de tela (Desktops, Tablets e Smartphones).
- **Navegação Intuitiva:** Menus organizados por categorias (Masculino, Feminino, Outlet).
- **Seção Hero:** Destaque para o lançamento principal (**Krypton One**) com chamadas para ação (CTA).
- **Categorias de Produtos:** Navegação rápida entre estilos (Casual, Esporte, Moderno e Futurista).
- **Grid de Produtos:** Vitrine visual destacando modelos e coleções.
- **Newsletter:** Campo para inscrição e recebimento de novidades por e-mail.
- **Redes Sociais:** Links integrados para Instagram, WhatsApp, TikTok e Facebook.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as tecnologias fundamentais da web:

1.  **HTML5:** Estruturação semântica de todo o conteúdo.
2.  **CSS3:** Estilização avançada utilizando:
    *   **Variáveis CSS:** Para facilitar a manutenção de cores e fontes.
    *   **Flexbox e Grid:** Para criação de layouts complexos e responsivos.
    *   **Arquitetura por Componentes:** CSS dividido em arquivos menores (header, footer, hero, etc.) para melhor organização.
3.  **JavaScript:** Utilizado para interatividade inicial e lógica de funcionamento do menu mobile.

## 📂 Estrutura de Pastas

```text
ecommerce-syntaxwear/
├── css/                # Estilos do projeto
│   ├── componentes/    # Estilos específicos de cada parte do site
│   ├── base.css        # Estilos base (tags padrão)

│   └── variables.css   # Definição de cores e fontes (Design System)

├── js/                 # Scripts de interatividade

```

## ⚙️ Como Executar o Projeto

Como este é um projeto front-end estático, você não precisa instalar dependências complexas. Siga os passos abaixo:

1.  Faça o download ou clone este repositório:
    ```bash
    git clone https://github.com/RicardoBortolini/ecommerce-syntaxwear.git
    ```
2.  Navegue até a pasta do projeto.
3.  Abra o arquivo `index.html` em qualquer navegador (Chrome, Firefox, Edge, etc.).
    *   *Dica: Se você usa o VS Code, recomendo a extensão **Live Server** para ver as alterações em tempo real.*
